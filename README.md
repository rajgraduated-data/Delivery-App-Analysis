**📦 E-Commerce Delivery Analytics Dashboard**

**📊 Project Overview**
This project analyzes e-commerce delivery performance using real-world-style data. It focuses on delivery efficiency, customer satisfaction, delays, and refund patterns to generate actionable insights.
The project includes:
A dataset containing order-level delivery details
A Power BI dashboard (.pbix) for visualization and insights

**📁 Project Files**
Ecommerce_Delivery_Analytics_New.csv → Raw dataset
Ecom-app.pbix → Power BI dashboard file

**🎯 Objectives**
Analyze delivery performance across platforms
Identify factors contributing to delivery delays
Understand customer satisfaction and ratings
Examine refund patterns and their causes
Provide data-driven insights for operational improvement

**📈 Key Insights**
Delivery delays impact customer ratings significantly
Higher delivery time correlates with increased refund requests
Certain product categories show more delays
Platform performance varies (App vs Web)

**🛠️ Tools & Technologies**
Power BI → Data visualization and dashboard creation
CSV Dataset → Data source
Excel / Python (optional) → Data preprocessing

**📊 Dashboard Features**
KPI cards (Total Orders, Avg Delivery Time, Delay Rate)
Interactive filters (Platform, Category, Date)
Visuals:
Delivery time distribution
Delay vs rating analysis
Refund trends
Category-wise performance

**🚀 How to Use**
Download the repository
Open Ecom-app.pbix in Power BI Desktop
Explore the interactive dashboard
Use filters to analyze different scenarios
